# authoredUnder _(Object property)_

[← Home](Home)

**IRI:** `https://w3id.org/ant#authoredUnder`

**Label:** authored under

## Definition

The perspective (observer-frame) a Translation is authored under / enacted within — the translation analogue of a Characterization's withinNetwork / perPractice. It makes a translation's frame derivable from the graph rather than only from file routing, so cross-perspective compilers and per-frame briefs can be reproduced from the union graph alone.
