# manifestsAs _(Object property)_

[← Home](Home)

**IRI:** `https://w3id.org/ant#manifestsAs`

**Label:** manifests as

## Definition

An actant is manifested as (present in the field as) an inscription: an optional, non-forced link recording that a named material trace is also a live actant — the same worldly thing read in two registers (C9). Unlike ant:inscribes (produces a separate trace) and ant:drawsOn (consumes one), this relates an actant to ITSELF in the other register. The shift from immutable mobile to fluid object is what confers agency: a frozen document merely circulates, whereas a living repository acts, so the same repository is both an inscription and an actant. The inscription is typically an ant:FluidObject but the range is ant:Inscription (not enforced). The textbook case is an open-source project, at once a community that governs and acts and a codebase tightly coupled to it. Recover the reverse reading (this inscription is also an actant) by querying the subjects of ant:manifestsAs. The two registers are non-disjoint; the relation is never inferred, only asserted. See ADR-0007.
