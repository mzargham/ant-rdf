# ProvAgent _(Class)_

[← Home](Home)

**IRI:** `https://w3id.org/ant#ProvAgent`

**Label:** PROV Agent role

## Definition

A role characterizing the target actant *under this perspective* as a prov:Agent — i.e., as something that bears responsibility for the influence it exerts. Used as ant:assignsRole on a Characterization. Does NOT assert prov:Agent typing globally. See ADR-0000 R2, R2.
